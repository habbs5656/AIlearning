# AI Learning

记录我在 AI / Python 方向的学习过程：代码、笔记、实验和项目。

## 目录结构

```
AIlearning/
├── notes/          # 学习笔记（Markdown）
├── code/           # 练习代码、小实验
│   └── srcnn/      # SRCNN 超分辨率：模型/训练/推理
└── projects/       # 完整一点的小项目
```

## 日常流程

1. 学完一个知识点 → 在对应目录下写代码或笔记
2. VS Code 左侧「源代码管理」→ 写一句提交说明 → 点 ✓ 提交
3. 点「同步更改」推送到 GitHub
